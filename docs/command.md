# Command reference

Generated by `task docs`; do not edit by hand.

```text
usage: livingproof-sim-mujoco [-h] [--model MODEL] [--steps STEPS]
                              [--timeout TIMEOUT] [--headless] [--version]

Load an MJCF XML or compiled MJB model and advance native MuJoCo physics.

options:
  -h, --help         show this help message and exit
  --model MODEL      MJCF .xml or MJB .mjb path; includes resolve relative to
                     XML; or builtin:falling (default: builtin:falling)
  --steps STEPS      maximum number of mj_step calls (default: 100)
  --timeout TIMEOUT  wall seconds including worker startup/model loading;
                     shutdown grace is at most 2 additional seconds (default:
                     10.0)
  --headless         run without viewer or graphics context (the only
                     supported mode) (default: True)
  --version          print tool, shared-library and engine versions as JSON,
                     then exit (default: False)

Example: livingproof-sim-mujoco --model builtin:falling --steps 100
--headless. Outputs one JSON result. Exit 0: requested steps completed; 2:
input/engine error; 124: wall timeout; 130/143: SIGINT/SIGTERM. Physics
execution is not a robot capability PASS. Use --version for engine and build
provenance.
```

# Contribute and get help

Report reproducible bugs or ask usage questions in the repository's
[issues](https://github.com/Living-Proof-Labs/livingproof-sim-mujoco/issues).
Include the command, trusted model or minimal example, expected and actual
behavior, and `livingproof-sim-mujoco --version` output. Remove private data.
No dedicated private security reporting route has been verified for this project;
do not post sensitive security details in public issues.

Contribute through a pull request using the
[adopted collaboration-guidelines v6.0.0](https://github.com/Living-Proof-Labs/collaboration-guidelines/tree/v6.0.0)
and [local agent instructions](https://github.com/Living-Proof-Labs/livingproof-sim-mujoco/blob/main/AGENTS.md).
Read the exact released guidance before relying on it. See the
[development guide](verification.md) and generated [Task reference](tasks.md)
for setup and checks. Independent review exercises the delivered artifact before merge.

Keep this a native MuJoCo command: no robot adapters, motor control, Gazebo or
umbrella runner. Native engine availability does not establish integration with
the Living Proof capability pipeline. Engine observations are not capability PASS.

Current rendered manuals, Documentation home, and source-directory navigation
are intentional reading-link exceptions to cross-repository pinning. They do
not replace pinned guidance, dependencies, workflows, or executable examples.

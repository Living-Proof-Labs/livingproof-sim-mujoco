# Contribute

Read [collaboration-guidelines v6.0.0](https://github.com/Living-Proof-Labs/collaboration-guidelines/tree/v6.0.0)
and this repository’s [agent instructions](https://github.com/Living-Proof-Labs/livingproof-sim-mujoco/blob/main/AGENTS.md)
for local scope and review requirements. The shared recipe owns engineering
standards; this manual owns MuJoCo installation, behavior and limitations.

See [verification](verification.md) for prepared development commands and review
procedures. Docker and Task 3.54.0 are host prerequisites. Host Task commands
enter the development container; inside it use `Taskfile.runtime.yml` to avoid
recursively starting Docker.

Current manual and documentation-home links are navigation exceptions only.
Dependency, shared workflow and guidance pins remain explicit released versions.
The current manual is development documentation, not a claim of released package
identity. [Version and source](context.md) records its exact source, installed
wheel and test run; historical manuals are not maintained.

No private security reporting destination is established in this manual.
